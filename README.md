# forcollege — Галерея

Адаптивная страница галереи, свёрстанная на HTML и CSS. Проект создан в рамках обучения и демонстрирует навыки построения адаптивного интерфейса.

## 📁 Структура проекта

## 🚀 Технологии

- **HTML5** — семантическая разметка страницы
- **CSS3** — стилизация и адаптивность
- **Git / GitHub** — контроль версий и хостинг репозитория

## 📱 Адаптивность

Вёрстка подстраивается под разные размеры экрана:
- мобильные устройства;
- планшеты;
- десктопы.
